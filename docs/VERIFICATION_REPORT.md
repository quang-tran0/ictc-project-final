# UART IP verification results

The complete 2026-10-10 regression executed **29 unique testcases in nine
groups, 33 runs: 23 PASS, 10 FAIL, 0 UNKNOWN**. No run timed out or reported
UVM_FATAL. All ten failures have been audited and attributed to the three
reproduced RTL defects in [BUG_REPORT.md](BUG_REPORT.md). RTL compliance is
**not signed off**. The original nine RTL files remain byte-for-byte unchanged.

## Execution and results

Environment: QuestaSim 2021.2_1, bundled UVM 1.2, system GCC for DPI linking,
100 MHz HCLK, 1 ns/1 ps simulation units. The final compile completed with
zero errors and zero warnings. Coverage was ON for every run. Directed tests
used seed 1; the duplex random test used seeds 1–5. Each duplex seed compares
192 TX frames and 192 RX reads across 24 configurations.

The checker self-test accounts for one PASS; DUT-only results are 22 PASS and
10 FAIL across 32 runs. Six unique DUT testcases fail. The runner returns
nonzero for the complete suite; known bugs are not converted into PASS.

| Failure | Testcases and evidence |

Independent Python decoding of pin waveforms confirms the stimulus and observed
parity. The timing reproduction also includes a passing idle-gap control and

## Coverage and remaining gaps

Coverage is merged from exactly the 33 databases in the completed manifest,
including completed failing runs. Stale databases are excluded. The merge
input list is [coverage_inputs.txt](results/coverage_inputs.txt).

| Measurement | Result | Meaning |
|---|---|---|
| Aggregate functional coverage | 97.50% | Tool aggregate across four covergroups |
| Functional bins | 449/450, tool reports 99.77% | Bin ratio differs from weighted covergroup aggregate |
| Bus group | 100% | Includes 18 register/direction cross bins, reserved errors and supported transfer types |
| Frame group | 100% | All 96 direction/width/parity/stop/oversampling cross bins and all 256 payload bins observed |
| Status group | 90% | FSR parity-error=1 is the sole missing bin |
| IRQ group | 100% | All 32 masks and both IRQ levels observed; does not establish parity-source IRQ correctness |
| Available DUT statement coverage | 1/1, 100% | Only one instrumented statement exposed by supplied RTL |
| Available DUT expression coverage | 4/5, 80% | Missing parity-error contribution |
| Available DUT toggle coverage | 550/596, 92.28% | Readable DUT hierarchy signals/ports |

Detailed reports: [functional](results/functional_coverage.txt) and
[DUT code](results/dut_code_coverage.txt). The code report's aggregate is 90.76%,
but protected `.vp` implementation bodies are not exposed as instrumented
source. This percentage is **not full internal RTL code coverage**. Frame
coverage records exercised conditions, including frames that fail parity or
data checks; it is not a compliance percentage.

UART-002 blocks proof that an asserted parity flag survives write-zero, clears
on write-one, and drives the enabled interrupt. Reading zero after W1C does
not close those requirements when the flag never sets. These cases must be
rerun on corrected RTL.

Independent configurations reset before initialization as specified in Chapter
3. Live divisor reconfiguration timing, empty-RBR values, divisor zero,
unsupported AHB sizes/bursts, stop-error handling and RX overflow behavior are
not claimed as covered because the supplied specification does not define
their complete expected behavior. FIFO wraparound, continuous duplex traffic
and BGE pause/resume are exercised within their respective scenarios.

## Reproduction and integrity

From the repository root, with Questa executables on PATH and a valid license:

```bash
./sim/regress.pl --seed 1       # Expected nonzero: 10 reproduced failing runs
make -C sim cov_merge cov_report
python3 sim/test_runner.py
sha256sum -c docs/rtl.sha256
```

For a single bug, use the commands in [BUG_REPORT.md](BUG_REPORT.md). Reports
and VPlan preserve each test's seed and expected/actual result. Offline tool
self-checks cover incomplete manifests, failed builds, stale coverage inputs,
timeouts, strict log classification, and UART waveform decoding. The isolated
UVM monitor self-test proved its incomplete-frame checks fail before the fix
and pass afterward. The four independent review findings and their fixes are
recorded in [REVIEW.md](REVIEW.md).

[rtl.sha256](rtl.sha256) records the original nine files from baseline
`9ccfd39`; [rtl_integrity.txt](results/rtl_integrity.txt) records the final
comparison. Source hashes for the tested implementation are archived in
[verification_sources.sha256](results/verification_sources.sha256).
The XLSX ZIP/XML structure and worksheet contents were validated. A visual
LibreOffice check could not run because the host's HarfBuzz/FreeType libraries
fail to link; CSV and Markdown copies provide directly reviewable content.

Delivery uses only branch `feat/uart-uvm-verification`; no merge is performed.
